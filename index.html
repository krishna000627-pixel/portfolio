QuestBlock

v285

Kotlin, Compose

The one I keep coming back to. Real tasks, like finishing a Class 12 chapter, turn into quests that earn coins, and coins buy minutes on the apps that eat my time. It started as an app blocker. Now it is a whole system for studying, focus and phone habits.

What it has
  • QuestsDaily, weekly, one-time, focus, routine and challenge types, with streaks and starter suggestions.
  • Coins and shopQuests pay coins and XP. Spend them on app time, boosts, badges and themes.
  • VaultPick the apps that distract you. Each one needs coins for a timed unlock, with a live countdown.
  • FocusA timer ring, strict mode, and a choice of which apps you may use during the session.
  • Study trackerChapters for every subject, marks, and attendance for school and coaching.
  • Player hubRanks, seasons, challenges, a weekly review and badges.
  • Usage statsDaily screen time split into study, coding, neutral and fun apps.
  • Rules and experimentsOptional switches, like Shorts blocked after the fun limit, so nothing is forced on you.
  • Reliability toolsBattery and autostart guide, a self test and a debug log for when Android kills it.
  • ThemesDozens of themes with their own effects, fonts and app icons.

App Hub

v37 and counting

Kotlin, Compose, Room

I got tired of unzipping and typing commands, so I built the thing that does it. Pick a zip, it pushes only the changed files to GitHub, GitHub builds and signs the APK, and I install it from the same screen.

What it has
  • DashboardEvery app at a glance: passing, failing, waiting to push, with Build and Deploy on each card.
  • DeployPick a zip, preview what changed, push it as one commit, optionally auto-install.
  • Safety checksWarns if the zip belongs to another app or is older than what is on GitHub.
  • Builds and releasesStep-by-step build log, release list with APK sizes, rollback to the previous build.
  • File browserSearch the repo, open files, delete one with a single commit. Undo last push is one tap.
  • Prompt MakerWrites the prompt I give Claude: new app, fix error, add feature, refactor. The latest build error is added automatically.
  • SigningCreates the keystore, sets the GitHub secrets, and backs up or restores keys.
  • Stays currentLive sync every 3 or 10 seconds, build notifications, APK download in the background on Wi-Fi.
  • More than appsNewer versions manage website projects too, and log in to GitHub, Vercel and Supabase.

BgBrowser

v11

Kotlin, WebView

Sites that read novels aloud stop the moment the screen locks. This browser keeps the page alive with a foreground service and a fake media session, so I can fall asleep to a chapter.

What it has
  • Keeps runningForeground service with a media session, wake lock and Wi-Fi lock.
  • Pause that remembersPause holds the voice at the current word and Play carries on from there. Works from the notification or a headset.
  • Sleep timerStops everything after a set time, for falling asleep mid-chapter.
  • Next pageOne tap to the next chapter, with your own CSS selector for stubborn sites.
  • Native voice bridgeSwaps the page’s speech for Android’s own text-to-speech.
  • Tor tabsSecurity levels, tracker blocking, a separate circuit per site. Weaker than Tor Browser, and the app says so.
  • LooksAMOLED black or light, accent colours, address bar on top or bottom.
  • Stays out of the wayLaunch on boot, restore tabs, a setup checklist for battery settings.

Android

Covers chosen apps with a fake screen and hides private photos and videos behind a PIN.

  • SecurityBlocks screenshots, themes, and an editable alert text.

How an update ships

  1. Zip the project and give it a version.
  2. App Hub compares it with the repo and pushes only what changed, as one commit.
  3. GitHub Actions builds the APK and signs it.
  4. I install it from App Hub and see if it survives.

This used to be a pile of Termux scripts. Same idea, fewer typos.
