Apps

01

QuestBlock

v285

Kotlin, Compose

The one I keep coming back to. Real tasks, like finishing a Class 12 chapter, turn into quests that earn coins, and coins buy minutes on the apps that eat my time. It started as an app blocker. Now it has a shop, ranks, a focus mode, weekly reviews and more themes than I planned.

02

App Hub

v37 and counting

Kotlin, Compose, Room

I got tired of unzipping and typing commands, so I built the thing that does it. Pick a zip, it pushes only the changed files to GitHub, GitHub builds and signs the APK, and I install it from the same screen. It also writes the prompt I paste to Claude when a build breaks.

03

BgBrowser

v11

Kotlin, WebView

Sites that read novels aloud stop the moment the screen locks. This browser keeps the page alive with a foreground service and a fake media session, so I can fall asleep to a chapter. There is a sleep timer, and Tor tabs because I wanted them.

04

v30

OpenGL

Live wallpapers from videos, GIFs and plain images. It shuffles on every unlock, pauses on a double tap, and lets go of the video decoder when I am away from the home screen so the battery lasts.

When I am busy, Aria answers my WhatsApp in Hinglish and says plainly that it is an AI. If I promise something, say confirming an arrival time, it keeps a follow-up so I do not forget. Runs on Groq or Gemini.

How an update ships

  1. Zip the project and give it a version.
  2. App Hub compares it with the repo and pushes only what changed, as one commit.
  3. GitHub Actions builds the APK and signs it.
  4. I install it from App Hub and see if it survives.

This used to be a pile of Termux scripts. Same idea, fewer typos.
